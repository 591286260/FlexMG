# Leakage-safe multi-scale graph learning for circRNA-disease association prediction

This repository contains the core implementation used for circRNA-disease association (CDA) prediction. The model combines circular-aware RNA sequence features, fold-specific disease GIP features, multi-scale bipartite graph encoding, graph attention, representation consistency regularization, and an MLP edge predictor.

The implementation is designed for five-fold pairwise cross-validation without label leakage: for every fold, the association graph, disease GIP kernel, and topology-dependent negative-sampling scores are reconstructed from training positives only. All known positive associations are used only to prevent their being sampled as negatives.

## Repository contents

- `extract_circrna_features.py` — circular-aware DNABERT feature extraction with multi-window pooling and circular k-mer composition.
- `cda_experiment.py` — main leakage-safe five-fold training, hyperparameter selection, ablation experiments, predictions, metrics, and CSV export.
- `parameter_comparison.py` — one-factor comparisons for learning rate, attention heads, and graph layers.
- `kmer_comparison.py` — circular k-mer composition comparison while preserving the selected protocol.
- `hop_comparison.py` — multi-hop / multi-scale comparison; hop count starts at one and the scale count is `max_hop + 1` because the original node-attribute view is retained as one scale.

No experimental datasets, trained weights, cached DNABERT models, or result files are included in this repository.

## Environment

Python 3.10 or newer is recommended. Install PyTorch matching your CUDA version first, then install the remaining packages:

```bash
pip install -r requirements.txt
```

CUDA is used automatically when available. Add `--cpu` to any command to force CPU execution.

## Input layout

Place each CDA dataset in a separate directory under `dataset/`:

```text
dataset/
├── circAtlas 3.0/
│   ├── interaction.csv
│   ├── Get_circRNAsequence.csv
│   └── circRNA_DNABERT.csv         # generated by the extractor
├── CircR2Disease V2.0/
│   └── ...
└── circRNADisease/
    └── ...
```

`interaction.csv` contains two headerless columns: `circRNA,disease`.

`Get_circRNAsequence.csv` contains circRNA identifiers and sequences. Wrapped sequence lines are supported. The extracted feature file must retain a `circRNA` column followed by numeric feature columns.

## Reproducible workflow

### 1. Extract circRNA sequence features

The default model is `zhihan1996/DNA_bert_6`. The model weights are downloaded from Hugging Face on first use.

```bash
python extract_circrna_features.py --dataset-root dataset
```

### 2. Run the main five-fold experiment

```bash
python cda_experiment.py \
  --dataset-root dataset \
  --output results \
  --datasets "circAtlas 3.0" "CircR2Disease V2.0" "circRNADisease" \
  --primary-negative hybrid_adaptive_0.82 \
  --seed 2026
```

For each fold, the code exports the train/validation/test predictions, disease GIP kernel, node embeddings, multi-scale attention weights, training history, decision threshold, and metric record as CSV files. Five-fold tables include folds 1–5 plus directly computed `Average` and sample `Std` rows.

### 3. Optional analyses

Run each comparison after the main experiment has written `selected_config.csv` and `primary_protocol.csv`.

```bash
# Learning-rate, attention-head, and layer comparisons
python parameter_comparison.py --dataset-root dataset --results results

# Circular k-mer comparison
python kmer_comparison.py --dataset-root dataset --results results --k-values 1 3 5 7

# Multi-hop / multi-scale comparison
python hop_comparison.py --dataset-root dataset --output results --max-hops 1 3 5 7
```

## Leakage-control protocol

For an outer fold, test positives are held out before graph construction. The training positives are split again into inner training and validation positives. Disease GIP is calculated from the inner-training interaction matrix only. The graph encoder sees the same inner-training graph only. Negatives are drawn from unknown pairs while excluding every known positive from the complete association list. Validation selects the classification threshold; test labels and test positives are not exposed to training, graph construction, GIP calculation, or negative ranking.

## Notes

- The code is provided without dataset files. Please ensure that dataset redistribution and sequence-model access comply with the relevant data and model licenses.
